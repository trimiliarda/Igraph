# Игра - СМСка

### Правила
---
Игроки садятся в круг. Каждый должен придумать себе один простой знак/ движение, который можно быстро показать одной рукой. Например, ”кулак”, знак и т.п. Игроки запоминают знаки друг друга. Выбирается ведущий, который встает в центр круга. Ведущий закрывает глаза. один из игроков запускает СМСку. Этот игрок показывает сначала свой знак, а потом знак другого игрока адресата СМСки. Показывать знак нужно так, чтобы адресат точно увидел его (получил СМС). СМСка запустилась. Игрок, получивший СМСку, передает ее кому-то еще. Ведущему разрешают открыть глава. Задача игроков незаметно для ведущего передавать СМСку.
Задача ведущего угадать у кого СМСка находится в данный момент. В этом случае игрок меняется с ведущим ролями. У ведущего есть неограниченное количество попыток.

---
## Ценность этой игры


### Вариация правил
1. Ограничить ведущего в попытках.
2. Ограничить время пребывания СМСки у одного человека.
